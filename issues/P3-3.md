# P3-3 — `SqlUpdate::set()` mixes two sides without clearing: `set("a = a + 1")` …

## Finding / 问题

- EN: `SqlUpdate::set()` mixes two sides without clearing: `set("a = a + 1")` writes only the raw side and `set(["b" => 2])` only the value side, so calling both accumulates instead of replacing.
- 中文: SqlUpdate::set() 两侧互不清空：set("a = a + 1") 只写原始侧，set(["b" => 2]) 只写值侧，两者都调会叠加而非替换。
- Where / 位置: `src/SqlUpdate.php:47-51`
- Verification / 验证: static / 仅静态推断
