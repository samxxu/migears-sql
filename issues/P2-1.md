# P2-1 — `SqlSelect::execute()` and `count()` call `$stmt->execute()` bare, …

## Finding / 问题

- EN: `SqlSelect::execute()` and `count()` call `$stmt->execute()` bare, unlike the DML classes which check it. In SILENT mode an execute failure silently returns an empty array or count 0 instead of SqlException — the residue of last round's P0.
- 中文: SqlSelect::execute() 与 count() 裸调 $stmt->execute()，而 DML 各类都做了检查。SILENT 模式下 execute 失败会静默返回空数组或 count 0，而不是 SqlException——上一轮 P0 的残留。
- Where / 位置: `src/SqlSelect.php:123,185`
- Verification / 验证: static / 仅静态推断
