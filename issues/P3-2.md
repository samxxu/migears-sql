# P3-2 — Table identifiers are handled inconsistently: …

## Finding / 问题

- EN: Table identifiers are handled inconsistently: `SqlInsert`/`SqlUpdate`/`SqlDelete` splice `$table` inside backticks (escapable) while `SqlSelect::from()` adds none. Column names gained a `/^\w+$/` check last round; table names did not.
- 中文: 表标识符处理不一致：SqlInsert/SqlUpdate/SqlDelete 把 $table 放进反引号内（可逃逸），SqlSelect::from() 则完全不引。列名上一轮已加 /^\w+$/ 校验，表名没有。
- Where / 位置: `src/SqlInsert.php:64, src/SqlUpdate.php:76, src/SqlDelete.php:35, src/SqlSelect.php:89`
- Verification / 验证: static / 仅静态推断
